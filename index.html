Tetris C#

Classic block-dropping puzzle game built in C#

About

Fast, lightweight single-player Tetris with hold, next-preview, and line-clearing scoring. Simple keyboard controls and pixel-art tiles make it easy to pick up and play.

Controls

  • ← / → — Move left/right
  • ↑ — Rotate clockwise
  • Z — Rotate counter-clockwise
  • ↓ — Soft drop
  • Space — Hard drop
  • C — Hold piece

How to Run

  • Unzip the downloaded folder
  • Double-click Tetris.exe
  • Or run in PowerShell:
.\Tetris.exe

System

  • Windows only
  • .NET runtime may be required

Troubleshooting

  • Check antivirus blocking
  • Install correct .NET runtime if needed
